Idempotencia

~9 min de lectura · 6 fuentes oficiales

1 · Resumen

Una operación es idempotente cuando ejecutarla una o varias veces con la misma entrada deja el sistema en el mismo estado. En un pipeline es lo que permite reintentar, reprocesar y hacer backfill sin duplicar ni corromper resultados.

3 · Problema que resuelve

Los pipelines fallan a mitad de camino y los sistemas de mensajería reentregan eventos. Si cada ejecución agrega filas sin control, un reintento duplica datos y los totales dejan de cuadrar. La idempotencia convierte el reintento en una operación segura.

10 · Código

Escribir por clave y asignar valores —no acumularlos— hace que repetir la carga no cambie el resultado.

SQL · MERGE por clave 
MERGE INTO ventas AS t
USING staging_ventas AS s
  ON t.id_venta = s.id_venta
WHEN MATCHED THEN
  UPDATE SET importe = s.importe,
             actualizado_en = s.actualizado_en
WHEN NOT MATCHED THEN
  INSERT (id_venta, importe, actualizado_en)
  VALUES (s.id_venta, s.importe, s.actualizado_en);
